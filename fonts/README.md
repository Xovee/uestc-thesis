# 随模板提供的字体

本目录随仓库和Release提供学校论文所需的字体文件：

- `simsun.ttc`：宋体
- `simhei.ttf`：黑体
- `times.ttf`：Times New Roman常规体
- `timesbd.ttf`：Times New Roman粗体
- `timesi.ttf`：Times New Roman斜体
- `timesbi.ttf`：Times New Roman粗斜体

模板默认优先使用这六个文件，从而在Windows、macOS和Linux等环境中获得一致的规定字体。
如果本目录中的文件不完整，模板会整体回退到系统中安装的`SimSun`、`SimHei`和
`Times New Roman`。

这些字体文件不受模板LPPL许可覆盖。项目维护者已取得在本非盈利项目中使用并随项目向
用户提供这些文件的明确许可；详细记录由维护者保留，待修订后在后续版本提供。该许可
不表示用户可以从项目中提取字体并用于其他目的。
