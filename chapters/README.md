# 示例章节

此目录保存匿名、可公开的论文示例章节。默认内容用于简要展示模板的主要功能和常用写法：

- `abstract.tex`：中英文论文共用的中文摘要与英文摘要；
- `symbols.tex`、`acronyms.tex`：中文论文的主要符号表和缩略词表；
- `chapter-1.tex`、`acknowledgements.tex`、`appendix.tex`、`achievements.tex`：中文示例内容；

建议新增章节时复制现有章节文件，重命名后在`main.tex`中增加一行`\input{chapters/文件名}`。不要把真实
论文、签名页或其他个人材料提交到公开仓库。
