# Example chapters

These anonymous examples show the main thesis structures and common syntax.

- `abstract.tex`: the Chinese and English abstracts, required in both language packages.
- `symbols.tex` and `acronyms.tex`: lists of symbols and abbreviations.
- `chapter-1.tex`: the main chapter example.
- `acknowledgements.tex`, `appendix.tex` and `achievements.tex`: the closing sections.

To add a chapter, copy an existing file, rename it, and add a corresponding
`\input{chapters/filename}` line in `main.tex`. Keep your thesis, signature pages
and other personal materials out of the public template repository.
