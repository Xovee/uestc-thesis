# 参考文献后端维护记录

当前使用XeLaTeX、BibTeX和gbt7714；uestcthesis.bst保存按学校要求适配的著录样式。
不同时保留Biber后端，避免维护两套容易产生差异的输出。

## 使用与迁移

- latexmk的编译入口不变；编辑器若手动选择文献工具，应从Biber改为BibTeX。
- 默认文献库为references.bib，仍使用`\uestcprintbibliography`输出。
- 自定义文献库使用`\uestcprintbibliography[my-references]`；多个库用逗号分隔，省略.bib。
- 删除旧的`\addbibresource{...}`。切换后端时清理旧编译辅助文件，再完整编译；不要删除章节、图片或文献库。
- `\cite{key}`为上标引用，`\citep{key}`为正文大小的方括号引用；两者均排序并压缩连续编号。

## 已知边界

- 普通文献隐藏DOI、URL和eprint；在线资源保留必要的访问地址、日期和电子载体标识。
  不能把所有含URL的记录一律视为在线文献，也不能为隐藏地址把在线资源随意改成期刊。
- BibTeX不具备Biber的完整Unicode姓名处理能力。带重音或特殊字符的姓名，尤其是需要
  缩写的名字，使用标准TeX写法，例如`Ar{\i}n, {\.I}nan{\c c}`，避免首字母被截断。
  中文姓名不受这个首字母缩写问题影响。
- 文献库需要唯一引用键；专名可用花括号保护大小写，例如`{LaTeX}`。
- Biber专属命令、数据模型和复杂文献筛选不自动兼容；不增加无测试的兼容层。
- 一般条目保持完整、不跨页；单条内容若超过整页可容纳高度，仍需要用户调整内容或分页。

自动测试包括19条字段与类型记录、引用真实尺寸、编号对齐、局部分页设置和六行长文献的
实际分页。测试只供维护者使用，不进入用户包，也不增加普通论文的编译步骤。
