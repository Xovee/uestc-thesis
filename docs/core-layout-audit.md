# 核心版式收口审计

## 目标与原则

本审计用于核验硕士、博士、中文论文和英文论文四种模式。官方规范及其Word输出是版式依据；测试文件只负责暴露问题，不反向决定模板样式。

规范条目、证据等级、实现边界和用户责任详见`standards-traceability.md`。

任何可能改变正式论文版面的`uestcthesis.cls`修改，都应先记录依据、展示修改前后效果并取得确认。测试文件和审计记录可以独立完善。

硕士与博士模式的差异目前仅出现在应当变化的学位名称、正文偶数页页眉、目录成果条目和成果页标题中。中文与英文模式按照各自规范切换章标题、目录名称、图表名称、引用名称、页眉和结尾部分标题。

## 修改纪律

本审计建立时没有修改`uestcthesis.cls`。发现疑点后，先制作最小测试和前后PDF对比；只有确认属于规范偏差且修改效果符合预期后，才调整核心类文件。
