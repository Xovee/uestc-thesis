# 学校规范可追踪矩阵

当前验收环境、自动混排间距的实现约定和测试方法见[维护说明](maintenance.md)。

## 目的

本文档把学校规范、官方Word样式、模板实现和维护者测试对应起来。它用于维护和审计，
不替代学校文件，也不把所有视觉参数误写成学校的硬性数值要求。

修改可能影响正式论文版面的`uestcthesis.cls`时，先说明变更目的及依据，区分学校要求、视觉复刻、实现修复和已授权的新功能。可直接进行本地试修；优先复用已有测试，缺少覆盖时再制作最小复现。完成后检查相关回归及修改前后的实际PDF，说明分页或兼容性影响。不得将实现选择表述为学校硬性要求。

## 证据等级

|等级|含义|使用方式|
|---|---|---|
|A|学校规范直接给出的文字、数值或结构要求|模板必须满足；变化时优先修正|
|B|官方Word模板或官方示例呈现出的视觉样式|用于复刻没有明确数值的细节|
|C|为了在LaTeX中稳定复刻Word效果作出的实现判断|必须记录原因并用PDF验证，不能宣称为学校硬性要求|
|D|取决于论文内容、提交类型或学院要求的用户责任|模板提示或提供接口，但不替用户决定|

## 英文论文的具体差异

英文规范明确说明：从`ABSTRACT`开始至论文最后一页只用英文书写，包括页眉；规范中
保留的中文仅用于中英对照。模板据此处理下列差异：

- 章号使用`Chapter N`，标题使用粗体Times New Roman，不使用中文黑体样式；
- 页面名称使用`Contents`、`Figures`、`Tables`、`Symbols`、`Acronyms`、
  `Acknowledgements`、`References`和`Appendix`；
- 图、表和公式引用名称切换为`Figure`、`Table`和`Equation`；
- 偶数页页眉、成果页标题和学位名称随硕士/博士选项切换为英文；
- 页面尺寸、正文字号、20pt行距、标题字号和段距、图表线宽、公式间距、页码体系与
  中文论文相同。

因此，英文选项不是把中文标签简单翻译一下，但也不建立另一套页面几何。目录3.5em
编号区域、长英文目录的自然词距等属于B/C级复刻参数，后续修改必须展示前后效果。

## 已知实现判断

以下参数服务于最终PDF效果，不能脱离上下文单独“纠正”：

- 底边距3.18cm与`footskip`、正文高度共同决定页脚位置；
- 图题和表题的4em边界用于长标题的两端对齐和视觉组织；
- 图表附注的显式间距需要连同浮动体、标题和段落胶水一起检查；
- `\raggedbottom`和标题分页惩罚用于避免标题孤立、单行独页等问题；
- 符号表和缩略词表不强制固定列宽，也不为少数超页情况加载额外跨页机制；
- 电子版默认不自动插入打印用空白背页。

## 用户仍需处理的事项

模板无法替用户确认下列内容：

- 从学校官方页面下载与学位类型相符的封面及扉页Word文件，填写后导出为`cover.pdf`；
- 正式提交时签署声明与授权页，必要时用扫描件替换项目提供的`declaration.pdf`；
- 匿名送审时删除或替换所有可识别身份的信息；
- 控制摘要字数和关键词数量，保证中英文内容对应；
- 保证图表清晰、单位和公式正确、参考文献真实完整、成果与论文相关；
- 按当次提交要求处理打印装订和纸质版空白背页；
- 在提交前以学院和研究生院最新通知为准，再次检查官方附件是否更新。

## F03表内单倍行距的实现依据（2026年9月9日）

官方Word规范的“表格”段落样式采用五号且未指定固定点数。对官方DOCX通过Word导出的
PDF实测：中文规范第29页同一单元格的宋体续行约13.56bp，英文约12.12bp；英文规范
第44页的宋体约13.68bp、英文约12.00bp。13.6 TeX pt约13.55bp，用作当前默认字体组合
的统一表内基线；纯英文略宽松，不宣称逐字体复刻Word的自然行距。

该数值控制单元格内的文字续行；20pt行高支撑盒配合原有arraystretch=.85继续提供
约17pt的普通短行间距。两者不是同一参数。内容较高时行高可自然增大。
用户显式选择small、normalsize等字号时仍采用该命令自身的行距；longtable及第三方
表格系统不在本次覆盖范围。验收环境为Windows + TeX Live 2026。
