# 中国学生与来华留学生规范完成度矩阵

## 用途

本文档逐项检查中国学生规范和来华留学生规范，并区分模板能力、示例内容和用户责任。
它用于判断首个公开版本是否已经具备发布条件，不替代学校规范。

状态含义：

- **已确认**：已有代码、测试和PDF视觉证据；
- **待复核**：功能已经实现，但缺少完整模式或真实环境的最终检查；
- **用户负责**：取决于论文内容、学位类型、学院要求或最终提交材料；
- **不自动实现**：模板有意不替用户作决定。

## 当前结论

核心模板功能已经基本覆盖两份规范。尚不能宣布全部完成的主要原因不是缺少大类功能，而是
以下验证工作尚未结束：

1. 使用真实macOS、Linux及Overleaf环境验证仓库字体和编译流程；
2. 编写简洁的使用手册，并使README、源码注释和手册职责一致；
3. 发布前重新检查官方附件、完整示例和用户压缩包；
4. 邀请未参与开发的学生完成一次从下载到编译的独立试用。

在上述工作完成前，不进入正式Release。
