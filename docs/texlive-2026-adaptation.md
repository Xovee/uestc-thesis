# TeX Live 2026适配与兼容性记录

日期：2026-09-06。范围：本仓库的开源模板，XeLaTeX + BibTeX + latexmk。

## 支持策略

TeX Live 2026为开发与验收环境，不再持续测试或支持2024等旧版本。
旧版本可能正常编译；遇到问题请先升级到2026。下文2024测试仅为本次适配的历史证据，
不构成后续版本的兼容承诺。当前证据来自Windows，
不据此宣称TeX Live 2025、macOS、Linux或Overleaf已经通过测试。
学校最新规范优先；跨版本微小字距、断行、表格宽度和分页差异本身不构成失败。
未降级或捆绑旧宏包。适配测试完成后，维护者决定将本机默认环境切换至2026并卸载2024。

## 变更依据与实现

此前同一份源文件在2024生成17页，在2026生成18页。差异集中于中西文、数字及
行内数学的混排间距，进而影响断行与分页；参考文献处理结果未变。

学校规定的A4、正文12pt、固定20pt行距、两字符缩进、标题与公式间距等继续沿用。
class显式设置`CJKecglue={\hskip .25em plus .1em minus .1em}`、
`xCJKecglue=false`与`CJKspace=false`，将自动混排间距及源码空格处理作为明确的
模板实现约定。0.25em是C级实现选择，不是学校规定的数值；普通源码词间空格仍保留。
未修改既有页面底边距和页脚的Word视觉校准值。

中英文示例将表格与引用说明合并为同一小节，避免内容很短的相邻小节造成不必要的
分页压力；未压缩规定字号或行距来追求旧版本页数。
中文结构表去除两侧默认列留白，消除2026基线原有的约0.96pt横向越界。

## 验收方法（2024命令仅保留作历史复现参考）

```text
python -m pip install -r tests/requirements.txt
python tests/run_regression.py --tex-bin C:/texlive/2026/bin/windows --build-dir build/regression-tl2026
python tests/run_regression.py --tex-bin C:/texlive/2024/bin/windows --build-dir build/regression-tl2024
```

每个环境编译21份文档，包括四种学位/语言组合、中英文完整示例、交叉引用、参考
文献类型与分页、题注引用、附录和编号边界、标题分页、符号与缩略语及版式尺寸。
新增PDF测量断言覆盖正文尺寸、行距、缩进、左右边距、自动混排间距、二至四级
标题字号、连续标题间距、公式居中及编号右对齐。TeX运行时检查公式四种上下间距。
完整示例仍需目视检查，不以页数完全一致代替质量验收。

`environment.json`保存实际工具路径与版本及主示例加载的宏包版本，
`layout-contract.layout.json`保存尺寸测量值；升级后应保留新的测试证据。

  未见重叠或内容裁切。2024与2026仍存在行内数学断行差异，保留为合理版本差异。

既有`aliascnt`等宏包提示须与致命错误区分；本记录不承诺日志完全无警告。
